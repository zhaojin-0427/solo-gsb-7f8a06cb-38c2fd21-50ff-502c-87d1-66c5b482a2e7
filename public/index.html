⌨️ 快捷键回放器

配置命令与快捷键（一至两步），选择当前作用域，输入按毫秒递增的按键事件，回放匹配与结算过程。

可回放示例

点击任一示例载入配置并立即回放，可在此基础上修改后重新运行。

1 · 命令配置

每步快捷键 = 修饰键（Ctrl / Alt / Shift / Meta，可组合、顺序无关）+ 主键（字母 / 数字 / Enter / Escape）。 第 2 步留空即为单步命令。点击输入框旁的 ⌨ 可直接按键录入，也可手工输入（如 shift+ctrl+k，失焦自动规范化）。

4 · 配置变更影响

以上方「命令配置」为旧配置，下方为可编辑的候选（新）配置。点击「比较配置」后， 对全局、编辑器、弹窗分别搜索使两套配置触发结果（命令 ID 顺序或触发时间）不同的按键样例： 按键取两套绑定中出现的规范化键，枚举一键与两键事件（首键 t=0，第二键 t=1 或 800ms）。 差异按（旧、新）触发结果组合分组，每组保留事件数最少的样例；结果与命令表行顺序无关。

5 · 目标命令修正

沿用上方「命令配置」「当前作用域」与「按键事件」。选择目标命令后，仅把已有事件的按键替换为 当前配置中出现的规范化按键（时间戳与事件数保持不变）：先回放原事件，目标已触发则返回零改动； 否则搜索至多 2 处不同事件的替换，使目标至少触发一次，按（改动处数、事件下标、替换键）升序取唯一方案 （替换为原键不计入改动）。限制：事件 ≤ 8 个、候选按键 ≤ 12 种。

匹配规则

  • 仅当前作用域与全局的绑定生效；同一序列优先当前作用域；同一作用域重复绑定会报错。
  • 不是两步前缀的单步命令，按下立即触发。
  • 命中两步前缀后等待 800ms：期限内第二键构成两步序列，则触发两步命令。
  • 失配或超时先结算前缀：有单步命令则触发，否则丢弃；失配键再作新起点。
  • 恰好第 800ms 到达的键：先结算前缀，再作为新键处理。
  • 输入结束时，结算仍待定的前缀。
